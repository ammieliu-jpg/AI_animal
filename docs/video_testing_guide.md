# 影像辨識測試：找影片、標註、跑測試

目標：用 **10–20 支不同情境**的真實影片測試模組 ①，產生可以寫進提案的準確率表。

> **資料原則**：報表裡的每個數字，都由程式比對「你填的標註」和「系統輸出」算出來。每支影片都要在 `sources.csv` 記錄**來源網址和授權**；缺來源、缺標註或缺區域檔的影片，報表會標成「不計入」，不會被猜測或補值。

## 1. 去哪裡找影片

| 網站 | 授權重點 | 授權頁面 |
|---|---|---|
| Pexels（pexels.com/videos） | 免費使用、不需標示出處、可修改；不可原樣販售或轉放到其他素材平台；**禁止用程式大量抓取（包含為了機器學習）** | [Pexels License](https://www.pexels.com/license/)、[Terms](https://www.pexels.com/terms-of-service/) |
| Pixabay（pixabay.com/videos） | 免費使用、不需標示出處、可修改；不可原樣販售；不可用來誤導 | [Content License](https://pixabay.com/service/license-summary/)、[Terms](https://pixabay.com/service/terms/) |
| 朋友或家人的居家影片 | 需要**書面同意**（注意事項第 31 點），畫面中有人時，那個人也要同意 | — |

⚠️ **請一支一支手動下載**，不要用程式或擴充套件批次下載。Pexels 的條款明確禁止自動化抓取。

**建議搜尋關鍵字**（英文搜尋結果比較多）：
- `cat drinking water`、`cat eating`、`cat bowl`、`kitten eating food`
- `dog drinking water`、`dog eating`、`dog bowl`
- `cat litter box`
- `cats eating together`、`two cats eating`（多隻）
- `pet camera`、`cat cctv`、`security camera cat`（監視器視角）
- `cat at night`、`dark room cat`（暗光）

## 2. 挑影片的原則

| 條件 | 為什麼 |
|---|---|
| **鏡頭不動**，或幾乎不動 | 居家攝影機是固定的；晃動或剪接的影片會讓追蹤中斷 |
| 看得到碗，而且寵物真的在吃或喝 | 才能測吃喝判斷 |
| 長度 10 秒到 2 分鐘 | 太短沒有測試價值，太長標註很累 |
| **情境要多元** | 貓狗都要有，單隻多隻都要有，也要有暗光、不同角度 |

建議組合（共 15 支左右）：

| 情境 | 支數 |
|---|---|
| 貓喝水／貓吃飯 | 各 3 |
| 狗喝水／狗吃飯 | 各 2 |
| 多隻一起吃 | 2–3 |
| 暗光或夜間 | 2 |
| 俯角或監視器視角 | 盡量多 |
| 寵物只是經過碗旁邊（應該**不算**吃喝） | 1–2（測試會不會誤判） |

## 3. 填 `sources.csv`（每支影片一列）

| 欄位 | 填什麼 | 範例 |
|---|---|---|
| video | 影片檔名，要和資料夾裡的檔名一模一樣 | `cat_drink_01.mp4` |
| source_url | 影片**頁面**的網址，不是下載連結 | `https://www.pexels.com/video/…` |
| license | 授權名稱 | `Pexels License` |
| downloaded_on | 下載日期 | `2026-11-10` |
| species | `cat` 或 `dog` | `cat` |
| n_pets | 畫面中有幾隻 | `1` |
| lighting | `day` 或 `dim` | `day` |
| camera | `top-down`、`side` 或 `cctv` | `side` |
| labels_done | 標註完成後填 `yes`。**沒有任何吃喝的影片也要填 `yes`** | `yes` |
| note | 備註 | 可以空白 |

建議把影片改成好認的檔名，例如 `cat_drink_01.mp4`；檔名請不要有空格。記得刪掉範例那一列。

## 4. 填 `labels.csv`（標註）

用影片播放器看，**每一段吃、喝、如廁**填一列：

| 欄位 | 填什麼 |
|---|---|
| video | 影片檔名 |
| behavior | `drinking`（喝水）、`eating`（進食）、`litter`（如廁），三選一 |
| start_s | 開始秒數，例如 `3.5` |
| end_s | 結束秒數 |
| note | 備註，例如「兩隻一起吃」，可以空白 |

標註原則：
- 頭或嘴在碗裡、正在吃或喝，才算。只是聞一下、經過，**不算**
- 中間抬頭不到 2 秒又繼續吃，算同一段
- 不確定的片段寧可不標，並在 note 寫「不確定」
- 秒數抓到 0.5 秒左右就夠了
- 影片裡完全沒有吃喝，就不用填任何一列，但要在 `sources.csv` 的 `labels_done` 填 `yes`。這種影片用來測試「會不會誤判」，系統在裡面判出的每一段吃喝都算誤判
- 每支影片標完後，記得在 `sources.csv` 的 `labels_done` 填 `yes`

用 Excel 編輯時，存檔請選「CSV UTF-8（逗號分隔）」，中文才不會變成亂碼。

## 5. 報表內容（`batch_report.xlsx`）

| 分頁 | 內容 |
|---|---|
| 總覽 | 各行為的召回率、精確率、時間 F1，以及判定規則說明 |
| 每支影片 | 每支影片計入與否、情境、找到幾段、偵測到幾隻 |
| 分組結果 | 依物種、光線、鏡頭角度、隻數分組的結果，可以看出哪些情況比較不準 |
| 標註比對 | 每一段標註有沒有被找到、被覆蓋多少 |
| 系統預測事件 | 系統輸出的所有事件，方便人工抽查 |
| 影片來源 | 每支影片的來源網址與授權 |

**指標怎麼解讀**
- **片段召回率**：你標的吃喝片段，系統找到多少（漏掉越少越高）
- **事件精確率**：系統說在吃喝的片段，有多少是對的（誤判越少越高）
- **時間 F1**：以每 0.2 秒為單位，綜合精確率和召回率
- **寵物偵測率**：寵物確定在畫面中的時間裡，系統有偵測到牠的比例

目前**不區分是哪一隻**在吃：兩隻貓一起吃時，只看「有沒有偵測到進食」。
