## 6. 已知限制（簡報第 13 頁已列出因應方式）

- **判錯碗**：碗在畫面上前後重疊時，可能判斷錯是哪一碗。改善方向是加入姿態模型，用鼻子位置判斷
- **編號不能跨片段**：同一隻寵物在不同影片，或剪接轉場後，編號可能不同。需要加入個體辨識
- **只用模擬資料驗證**：90% 對 60% 的比較來自自行設計的模擬資料，不代表真實準確率
- **「留意」比例偏高**：約 1 成天數。產品上可以只推播「建議諮詢」
- **Claude 撰寫尚未實測**：要有 API 金鑰才能確認實際文字品質
