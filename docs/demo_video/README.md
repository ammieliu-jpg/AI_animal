# Demo 影片初稿：旁白稿與修改說明

- 影片：`PetSentinel_demo_draft.mp4`（1920×1080，3 分 00 秒，已燒入中文字幕）
- 字幕檔：`subtitles.srt`，可匯入剪映、CapCut、Premiere 等剪輯軟體修改或重新配旁白
- 產生腳本：`build_video.py`（每一幕的畫面和字幕都寫在 `SCENES` 裡）

## 怎麼用

1. **直接當初稿**：字幕版可以直接上傳，評審不聽聲音也看得懂
2. **加上旁白**（建議）：照下表的時間念稿，用手機錄音後放進剪輯軟體，對齊字幕即可
3. **換成真實畫面**：拿到真實居家影片後，把「① 看懂行為」那一幕換成 `annotated.mp4` 的片段

⚠️ 需要修改的地方：
- 結尾的【團隊名稱】
- 「① 看懂行為」使用的是素材影片的實測畫面，上傳前請確認影片授權，並在影片說明欄註明來源
- ② 和驗證結果的畫面已標示「模擬資料」，請保留
